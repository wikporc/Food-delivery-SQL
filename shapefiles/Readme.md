# Introduction

**This directory contains files with geographic data for Belgium, mostly in [shape-file ESRI](https://en.wikipedia.org/wiki/Shapefile)  format**. 

`Belgium-4-Digit-Postcodes-2020` - The map of Belgian municipalities, taken from  opendata.brussels.be

`belgium_map_simplified` - The map, simplified (by caveeagle) to ~1 kilormeter

`provinces` - map, grouped by provinces

`postal_codes.csv` - The dataset of postal code to region correspondence.
