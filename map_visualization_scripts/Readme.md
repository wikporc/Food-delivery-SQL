# Introduction

**This directory contains scripts in the [Jupyter Notebook](https://en.wikipedia.org/wiki/Project_Jupyter) format.**

# Files

interactive_maps_extended.ipynb - interactive map by regions

interactive_maps_simple.ipynb - interactive map for testing

interactive_provinces_map.ipynb - interactive map group by provinces

static_map.ipynb - creating static maps 

static_map_extend.ipynb - creating others static maps

# Libraries

Interactive maps need some specific python libraries:

Standart libraries for working with datasets: 
`pandas`, `matplotlib`, `numpy`

Extentions for pandas - the library `geopandas`

folium - the library for making interactive maps (with export to html 
branca - the library for making "temperature" map
